## Déployer sur GitHub Pages après validation

1. Créer un dépôt public dédié au portfolio sur le compte GitHub choisi.
2. Décompresser l’archive et copier **le contenu du dossier** à la racine du dépôt (`index.html` doit être à la racine).
3. Sur GitHub : `Settings` > `Pages` > `Build and deployment` > `Deploy from a branch`, choisir `main` et `/(root)`.
4. Copier l’URL exacte affichée dans GitHub Pages et l’ajouter dans CVDesignR (champ de site personnel si proposé, ou profil GitHub renvoyant vers le portfolio).

La présence d’une archive ZIP ne signifie pas que le site a été publié ou qu’une URL publique fonctionne.
